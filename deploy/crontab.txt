# news-notifier scheduled scrapers — installed by deploy/setup.sh.
# __APP_DIR__ is substituted with the real clone path during install.
#
# Staggered across each 30-minute window so the Playwright-based jobs
# don't spin up Chromium at the same moment on a small VPS, and none of
# them land on :00/:30 exactly (avoids thundering-herd-style contention
# some cron-adjacent schedulers hit at round times — not a real concern on
# a single dedicated box, but harmless to keep spread out regardless).
#
# The Beyblade jobs are the EU multi-market pilot scrapers. They replace
# scripts/track_delivery_date_playwright.py and
# scripts/scrape_hasbro_catalog.py, which were .se-only and are no longer
# scheduled — see deploy/README.md. Do NOT re-add those without removing
# these first: both systems track the same products and would produce
# duplicate Discord alerts from diverging state.
#
# --send-discord is required. Without it both scrapers run in dry-run
# mode and merely log what they would have sent.
0,30 * * * * __APP_DIR__/deploy/run.sh pilot/eu_multimarket/track_delivery_multi.py --send-discord >> __APP_DIR__/logs/delivery-multi.log 2>&1
10,40 * * * * __APP_DIR__/deploy/run.sh pilot/eu_multimarket/scrape_catalog_multi.py --send-discord >> __APP_DIR__/logs/catalog-multi.log 2>&1
20,50 * * * * __APP_DIR__/deploy/run.sh scripts/scrape_hypixel.py >> __APP_DIR__/logs/hypixel.log 2>&1
